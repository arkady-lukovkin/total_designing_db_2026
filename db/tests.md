# Протокол проверки FoodExpress

Результаты запусков от 10 ноября 2026. PostgreSQL 15.19, схема `lukovkin_food`, пользователь `inspector`, часовой пояс Europe/Moscow.

| Операция | Результат |
|---|---|
| Создание схемы | Созданы 12 таблиц, 8 enum-типов, функции, процедуры, триггеры и представления |
| `insert_test_data(10)` | Таблицы заполнены в соответствии с заданным распределением, связи корректны |
| Повторное заполнение | Новый пакет добавляется к существующим данным |
| `erase_test_data()` | Все 12 таблиц пусты; повторный вызов выполняется без ошибки |
| `add_product(...)` | Блюдо добавляется с UUID; отсутствующие связи и недопустимые значения отклоняются |
| Изменение отзывов | Рейтинг пересчитывается при INSERT, UPDATE и DELETE; после удаления последнего отзыва равен NULL |
| `get_statistic()` | Пять требуемых колонок, одна строка на ресторан, учитываются доставленные заказы |
| `courier_salary()` | Проверены пороги 0/150/151/250/251/500/501, сохранение применённой ставки, повторный вызов и увольнение |
| `how_much_money` | Восемь требуемых колонок, пропущенные месяцы заполнены, переход года и предыдущая комиссия учтены |
| Права inspector | Работают операции со схемой и чтение системных каталогов; повторная выдача прав сохраняет существующий пароль |
| Восстановление архива | Выполнено в отдельной пустой базе с заранее подготовленной `exts`; после выдачи прав операции работают под inspector |

## Объём данных

При `insert_test_data(10000)` получены 50 000 заказов, 150 196 позиций, по 50 000 отзывов и оплат, 60 000 строк истории выплат. Всего — 550 196 строк. Очистка предыдущего набора, генерация и COMMIT заняли 45.127 секунды в среде с 2 CPU и 1.5 GiB RAM.

Суммы позиций и заказов, успешные оплаты, рейтинги после генерации и суммы выплат согласованы. `get_statistic()` вернул 10 000 строк, денежный отчёт — шесть месяцев.

## Резервная копия

`foodexpress_lukovkin.backup` создан через `pg_dump -Fc --schema=lukovkin_food --no-owner --no-acl`. Размер — 79 243 байта. SHA-256: `c1ebf15982d73b4fe02112b8b86aefe6cc16938779a913b17dc83534e5b444f4`.

Архив содержит схему `lukovkin_food` с пустыми таблицами. Схема `exts` и расширение `uuid-ossp` подготавливаются отдельно. Порядок восстановления приведён в `README.md`.
