# Протокол ручной проверки FoodExpress

Проверка выполнена 14 ноября 2026 в PostgreSQL 15.19 под пользователем `inspector`. Схема `lukovkin_food`. SQL-скрипты установлены в чистой базе, архив восстановлен в другой.

| Операция | Наблюдаемый результат |
|---|---|
| Установка SQL и выдача прав | 12 физических таблиц, в том числе `"order"` и `payment`, 17 пользовательских триггеров. Денежный отчёт `how_much_money` доступен как представление |
| `insert_test_data(10)` и повторный вызов с 1 | 55 заказов и 55 попыток. 33 успешных, 11 с ошибкой, 11 в обработке. Заказы получили соответствующие статусы |
| Суммы | Итоги 55 заказов от 1 059,87 до 4 989,57 ₽, средний чек 3 315,07 ₽. Расхождений со стоимостью позиций и суммами попыток нет |
| Повторная оплата | Заказ перешёл из ожидания в ошибку, затем в оплаченный. Сохранены две попытки, одна успешная |
| Ограничения оплаты | Вторая успешная попытка отклонена с `23505`, сумма не равная итогу — с `23503`, доставка неоплаченного заказа — с `23514` |
| Адрес, ресторан и отзыв | Чужой адрес, блюдо из другого ресторана и отзыв на отсутствующее в заказе блюдо отклонены |
| `add_product` и рейтинг | Создано блюдо с оценкой 5, первый отзыв дал рейтинг 3, удаление последнего отзыва вернуло NULL. Прямое присвоение оценки существующему блюду без отзывов отклонено с `23514` |
| `TRUNCATE review` | Рейтинги по удалённым отзывам сброшены. Начальная оценка 5 у блюда без отзывов сохранилась |
| `get_statistic()` | На первом пакете 11 строк для 11 ресторанов. У ресторанов с оборотом лидеры заполнены. При шести отдельных вызовах для ресторана с двумя равными лидерами выпали оба клиента |
| План статистики | `EXPLAIN (ANALYZE, BUFFERS)` на 5 000 заказов: по одному проходу по таблицам заказов и позиций. Сортировки по случайному числу нет |
| `courier_salary()` и `how_much_money` | Для первого набора доступны 66 строк зарплаты и 4 месяца денежного отчёта |
| Очистка | Отдельный `TRUNCATE payment` при существующих заказах отклонён. Два последовательных вызова `erase_test_data()` выполнены без ошибки |
| Восстановление | Архив восстановлен после подготовки `exts`. После применения `grants.sql` под `inspector` отработали генерация всех трёх статусов, статистика и очистка |

`foodexpress_lukovkin.backup` создан в PostgreSQL 15.19 командой `pg_dump -Fc --schema=lukovkin_food --no-owner --no-acl`. Архив содержит схему с пустыми таблицами. Размер 87 388 байт, SHA-256 `1508467b0d5090fbe5bce19c839456aaa30259f5deb5ecb6bb3fa57ef88d541d`.
